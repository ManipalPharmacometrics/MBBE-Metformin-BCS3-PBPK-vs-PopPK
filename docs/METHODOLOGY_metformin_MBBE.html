Metformin XR virtual bioequivalence — methodology in plain language

What this project does, in one sentence: we use two different computer models of metformin extended-release (XR) tablets to answer the same regulatory question — “how much can the tablet’s release rate drift before it would fail a bioequivalence (BE) study?” — and we check whether the two models give the same answer.

The two models are:

  1. a PBPK model (physiology-based, built in PK-Sim), and
  2. a PopPK model (population-PK, fitted in Pumas).

The single formulation “knob” we turn is T50 — the Weibull release time of the tablet (hours). Bigger T50 = slower release. Everything below explains, in simple terms, exactly what was done on each side and how they are compared.

A note on the plan. The intended PopPK absorption model is the Weibull-release model described in Part 2 — the same release law the PBPK tablet uses. This is the baseline throughout; a simpler first-order-absorption form is retained only as a secondary sensitivity model.

0. The concepts you need first (30-second versions)

  • Bioequivalence (BE). Two products are “bioequivalent” if the body is exposed to the drug almost identically. Practically: the 90% confidence interval of the test/reference ratio (the GMR) for peak concentration (Cmax) and total exposure (AUC) must sit entirely inside 0.80–1.25. The test is the two one-sided tests (TOST) procedure.
  • Virtual / model-based BE (VBE / MBBE). Run that BE study on a simulated population instead of in real people.
  • Safe space. The range of the formulation knob (here T50) where the product not only passes BE but a realistic-sized study has ≥ 80% power to pass. The safe space is narrower than the raw BE range, because power falls off before the ratio actually leaves 0.80–1.25.
  • Why two models? PBPK and PopPK are the two standard MBBE routes. If they place the safe-space boundaries in the same place, that is strong evidence the boundaries are real and not an artifact of one modelling choice. That agreement is our headline deliverable — “decision equivalence.”

We are reproducing the method of Morris et al., AAPS J 2026 (a long-acting injectable safe-space + type-I-error paper), but applied to an oral MR drug.

1. The PBPK side (PK-Sim) — “build the physiology, dissolve the tablet”

Goal: a mechanistic model where the drug moves through actual organs, and the only thing we change between formulations is how fast the tablet releases the drug.

All modelling and simulation on this side is done entirely in PK-Sim (the small-molecule PBPK builder). No other tool is used — no MoBi, no scripting layer — everything is built and run in the PK-Sim GUI.

1.1 What a PBPK model is (and what PK-Sim gives us)

Unlike a compartmental model (a few abstract boxes fit to data), a PBPK model represents the body as its actual organs — gut, liver, kidney, muscle, fat, brain, etc. — each with a real blood flow, volume, and tissue-to-plasma partitioning. Drug-specific properties (molecular weight, lipophilicity, solubility, permeability, protein binding, and transporter/enzyme kinetics) drive how the drug moves through that physiology. PK-Sim holds the physiology database and assembles the model from a small set of building blocks: Compound (the drug), Formulation (how it is released), Administration Protocol (dose/route), Individual or Population (the physiology), and Simulation (which ties them together).

1.2 The starting model — a published, validated metformin model

We did not build metformin from scratch. We loaded the published open-source metformin PBPK model (a PK-Sim project snapshot) and ran it in PK-Sim:

  • Model source: https://github.com/Open-Systems-Pharmacology/Metformin-Model
  • Model paper: Hanke et al., Clin Pharmacokinet 2020 — https://doi.org/10.1007/s40262-020-00896-w
  • It was validated against 39 clinical studies (0.001–2550 mg, oral + IV). We confirmed the install by reproducing the model’s own immediate-release validation (the Tucker 1981 clinical overlay) before changing anything. The model ships covering oral immediate-release and IV only — the disposition (distribution + clearance) backbone comes for free; the extended-release layer is what we add (§1.4).

1.3 The drug — how metformin behaves in the body

The concrete metformin properties that matter for this study (all carried in the PK-Sim Compound):

  • Small, hydrophilic base, MW ≈ 129.16 g/mol (free base); high aqueous solubility but low passive permeability → a BCS class III drug (dissolves easily, crosses membranes poorly).
  • Absorption is transporter-mediated and occurs high in the gut — there is an effective absorption window: drug that has not been released before it passes the upper small intestine is absorbed less well. This matters for slow-release tablets (see limitations).
  • Cleared almost entirely by the kidney (renal secretion, essentially no hepatic metabolism), via organic-cation transporters. The model carries the canonical Hanke transporter set — OCT1, OCT2, MATE1, PMAT (renal/hepatic/intestinal cation transport) — which is what makes metformin’s disposition mechanistic rather than a fitted clearance.

Because clearance is renal and transporter-mediated and does not depend on how the tablet releases, clearance and volume are the same for every formulation — a fact we rely on later when interpreting the PopPK fit (§2.3).

1.4 Add the extended-release (XR) tablet as a Weibull dissolution

Metformin XR (e.g. Glucophage XR) is a slow-release matrix tablet. In PK-Sim we attach a Weibull dissolution Formulation to the compound — the fraction of drug released by time t:

F(t) = 1 − exp( −((t − lag)/T50)^β )
  • T50 = the Weibull scale = the release time. This is the single formulation knob (the CQA) we vary.
  • β = the Weibull shape = how S-shaped the release is. We hold β fixed at 1.0 for every tablet — so across the study only the scale changes, not the shape.
  • Reference T50 ≈ 3 h (representative of Glucophage XR in-vitro release; cf. Timmins et al., Clin Pharmacokinet 2005; Stepensky et al., Biopharm Drug Dispos 2002).

Dose convention (used consistently for every simulation): a clinical 500 mg metformin HCl tablet = 390 mg free base (factor 0.78; MW base 129.16 vs salt 165.62). PK-Sim doses in free base, single dose, fasted, 24 h simulation. Keeping this identical across all tablets is what makes the test-vs-reference comparison valid.

1.5 The formulation sweep

We built 8 tablets by changing only T50: 1.0, 2.0, 3.0, 3.5, 4.0, 5.0, 6.0, 7.0 h (3.0 h = reference). β = 1.0, dose, population and everything else are held fixed — so any difference in the blood profile is attributable to release rate alone.

1.6 The virtual population

For each of the 8 tablets we ran a population simulation of 24 virtual subjects built from PK-Sim’s population module:

  • Template: European healthy adults, ages 18–55, BMI 18.5–30, 50/50 male/female.
  • PK-Sim varies each subject’s physiology (organ sizes, blood flows, transporter expression) in an internally consistent way, so the 24 subjects are genuinely different bodies.
  • Crucially, PK-Sim uses the same 24 physiologies under every tablet. So test-vs-reference is a fully paired 2×2 crossover (the same person effectively “takes” both tablets) — the cleanest possible average-BE setting, with no between-subject noise from mismatched arms.

Output per tablet: dense peripheral-venous plasma concentration–time curves (a 3-minute grid, 0–24 h) for all 24 subjects, exported to CSV — the input to everything downstream.

1.7 Known limitations / scope (stated honestly)

  • This is a methodology platform, not an absolute-accuracy exercise. The population over-predicts absolute metformin exposure by roughly 2-fold vs clinic. That is deliberately accepted: bioequivalence is a relative test/reference comparison, so a shared absolute offset cancels and does not affect the GMR/TOST conclusions.
  • Slow tablets show flip-flop kinetics. When release is slower than elimination, the terminal decline reflects the release rate, not true elimination. This inflates the extrapolated AUC_inf for the slowest tablets, so AUC₀–t is the primary AUC endpoint (AUC_inf is reported alongside but treated cautiously).
  • The absorption window caps the slowest tablets. With very slow release, some drug passes the absorption window before dissolving (fraction absorbed falls from ~0.8 toward ~0.5), which is a real mechanistic feature of metformin, not a modelling error.

1.8 BE endpoints straight from the PBPK profiles

For each subject we compute, by non-compartmental analysis (NCA): - Cmax (peak), - AUC₀–t (exposure over 0–24 h; the preferred endpoint for XR), and - AUC_inf (extrapolated to infinity).

These per-subject numbers are the PBPK “truth” we later compare against.

Software: PK-Sim — the small-molecule PBPK tool; docs https://docs.open-systems-pharmacology.org/working-with-pk-sim/pk-sim-tutorial. The metformin model was loaded as a PK-Sim project snapshot from the source in §1.2.

2. The PopPK side (Pumas) — “pretend you only have a clinical study, and fit a model”

Goal: answer the honest real-world question: if all you had was an ordinary, sparse clinical BE study, would a fitted PopPK model reach the same BE decision the mechanistic PBPK model does?

So we deliberately throw away the PBPK detail and rebuild a PK model from a realistic, noisy, sparsely-sampled dataset.

2.1 Turn the PBPK “truth” into a realistic clinical study

  1. Sparse-sample each subject’s dense PBPK curve at a normal clinical BE schedule: 0.5, 1, 1.5, 2, 3, 4, 5, 6, 8, 10, 12, 16, 24 h (13 samples).
  2. Add measurement noise: a 15% proportional (assay) error on each sample. Without noise the simulated study is unrealistically clean and the power/type-I analysis is meaningless — the same point Morris and the FDA guidance stress.
  3. Write it out in standard NONMEM/Pumas format (dose row + observation rows per subject), keeping the T50 label and the subject id (to preserve crossover pairing).

2.2 The PopPK model — a Weibull-release absorption model (the original plan)

This is the key modelling choice. On the PBPK side the tablet dissolves by a Weibull law; we use that same Weibull law as the absorption input on the PopPK side, so the two models speak the same mechanistic language.

Metformin XR is dissolution/release rate-limited (its slow tail — “flip-flop” kinetics — is set by how slowly the tablet releases, not by elimination). So we let the Weibull release be the absorption, with no separate absorption-rate constant (there is nothing extra to identify). The model is a 1-compartment disposition fed by a Weibull release:

release rate constant   h(t) = (γ/α) · ((t − lag)/α)^(γ − 1)      (for t > lag)
depot (undissolved drug) Depot'   = −h(t)·Depot,   Depot(0) = Dose
central (in body)        Central' =  h(t)·Depot − (CL/Vc)·Central
concentration            C(t)     =  Central / Vc

This makes Depot(t) = Dose · exp(−((t−lag)/α)^γ) — exactly the Weibull release curve the PBPK side uses. So:

  • α (the fitted in-vivo release scale) is the direct analog of the PBPK T50 — it varies with formulation;
  • γ is the in-vivo input shape — the in-vitro dissolution (PBPK β = 1.0) folded together with gut absorption and transit; it is estimated, not fixed to β = 1 (in the per-arm baseline it comes out ≈ 1.7; in the disposition-constrained IVIVC variant it is a single shared value ≈ 0.8 — see §4). It does not vary by formulation (neither does the shape on the PBPK side);
  • CL, Vc are clearance and volume (disposition).

Because it uses the same release law, the PopPK model can reproduce the PBPK profile shape at each formulation — which the older first-order model could not.

On the 1-compartment disposition. We use one central compartment. In the published metformin population-PK literature both structures appear: most models are two-compartment (metformin shows a mild biexponential decline and red-blood-cell uptake), but a one-compartment model with first-order absorption and lag is documented as adequate for immediate-release metformin (e.g. the review by Wang et al. 2022, and the Korean FDC analysis, Chung/Kim et al. 2018). For this relative BE comparison the one-compartment disposition is a reasonable, transparent choice; a two-compartment disposition is the natural sensitivity/extension if the terminal phase needs it.

Variability added in the model: - Between-subject variability (IIV): log-normal random effects on α, CL, Vc (diagonal Ω). γ and lag are kept as fixed effects for stability with sparse data. - Residual error: proportional (the model’s estimate of the 15% assay noise).

2.3 Fit the model — this is a real re-fit

Each formulation arm is fit by population maximum-likelihood estimation. We reuse no PBPK parameter — the model is estimated from the sparse noisy data alone, exactly as it would be with a real clinical study.

One structural caveat — release vs disposition (flip-flop). Metformin XR is release-rate-limited, so its terminal decline is set by the slower of two processes (release vs elimination). In a one-compartment model these two are not separately identifiable from a single arm — “slow release + fast elimination” and “fast release + slow elimination” produce the same curve. If every arm is allowed its own clearance and volume, the fit can absorb the formulation effect into disposition and leave the release scale α nearly flat. The physiologically correct constraint removes the ambiguity: clearance (CL) and volume (Vc) are properties of the drug and subject, not of the tablet’s release rate, so they are held formulation-independent (shared across arms). Only the release scale α then varies by formulation (γ stays shared), and α becomes an identifiable, monotonic in-vivo analog of T50 (an in-silico IVIVC). Constraining disposition also smooths the endpoint-vs-formulation relationship, so it can shift the safe-space boundaries relative to an unconstrained per-arm fit — the release-vs-disposition split and the safe space are coupled. The safe-space comparison should therefore be reported from a single, consistent fit, stating which one.

2.4 Re-simulate and re-derive the same endpoints

From the fit we reconstruct each subject’s dense predicted profile (0–24 h), then run the same NCA as the PBPK side to get per-subject Cmax / AUC₀–t / AUC_inf — same column layout, same definitions. Now the two methods produce endpoints that can be compared apples-to-apples.

3. Comparing the two — the safe space and “decision equivalence”

Both sides now have per-subject Cmax/AUC at each T50. We run the identical statistics code on each:

  1. GMR(T50) with 90% CI — paired TOST vs the reference (T50 = 3 h). BE passes if the whole 90% CI is inside 0.80–1.25.
  2. Virtual BE power curves — for a fine grid of T50 values and two realistic study sizes (n = 48 and n = 86), resample crossover trials (bootstrap of the 24 paired subjects), inject the within-subject variability measured for metformin ER (Cmax CV ≈ 12.2%, AUC ≈ 11.2%; source: FDA NDA 212595 clinical-pharmacology review), run TOST, and record the fraction of trials that pass = power.
  3. Safe space = the T50 range around the reference where power ≥ 80%.
  4. A joint endpoint (must pass both Cmax and AUC₀–t) is also computed.

Because the only difference between the PBPK and PopPK curves is how the per-subject Cmax/AUC were produced (mechanistic NCA vs fit-then-NCA), any gap between them is exactly the effect of using a fitted sparse-data PopPK model instead of the full physiology. That gap is what “decision equivalence” measures.

4. What we found

Decision equivalence (the primary result) — from the licensed Pumas fit. The PopPK model was fit to each formulation arm and its safe-space boundaries put next to the PBPK truth. They nearly coincide: the fitted sparse-data PopPK model reaches the same BE conclusions as the mechanistic PBPK model.

Safe-space boundaries (power ≥ 80%), PBPK vs PopPK — licensed Pumas run:

Endpoint n PBPK [lo, hi] h PopPK [lo, hi] h
Cmax 48 [2.00, 4.15] [1.95, 4.05]
Cmax 86 [1.80, 4.25] [1.75, 4.15]
AUC₀–t 48 [1.00, 4.60] [1.00, 4.55]
AUC₀–t 86 [1.00, 4.70] [1.00, 4.65]
AUC_inf 48 [1.00, 4.95] [1.00, 4.95]
Joint (Cmax & AUC₀–t) 48 [1.95, 4.10] [1.90, 4.05]
Joint (Cmax & AUC₀–t) 86 [1.85, 4.25] [1.75, 4.15]

Reading it: Cmax is the binding endpoint (AUC stays equivalent over a much wider T50 range). The joint safe space is T50 ≈ 1.9–4.1 h, and the PBPK and PopPK methods agree to within ~0.05–0.1 h — i.e. decision equivalence holds.

4.1 In-vivo release scale (IVIVC) — a secondary, optional analysis

Ideally the fitted release scale α would recover each tablet’s T50 (an in-silico IVIVC). In the fit that produced the safe space above (each arm fit with its own disposition), α comes out nearly flat (≈1.4–1.7 h across T50 = 1–7 h) — not an IVIVC. This is the expected one-compartment flip-flop ambiguity: from a single arm the model cannot separate the release rate from the elimination rate, so the formulation effect leaks into the (freely fitted) clearance and volume instead of into α.

To recover the IVIVC we constrain disposition to be formulation-independent (clearance and volume are properties of the drug+subject, not the tablet — §2.3) and let only α vary. Then α climbs monotonically with T50:

PBPK T50 (h) 1.0 2.0 3.0 3.5 4.0 5.0 6.0 7.0
α, per-arm fit (flat) 1.4 1.6 1.7 1.6 1.7 1.7 1.7 1.7
α, disposition-constrained (IVIVC) 3.2 4.1 5.4 5.7 6.5 7.6 9.1 11.0

Constraining disposition also smooths the endpoints and so shifts the safe space (they are coupled — §2.3). This IVIVC analysis is therefore reported separately from the primary per-arm safe space; the constrained-fit α column above is from the license-free cross-check and would be finalized by a joint population fit.

4.2 Release shape γ — fixed vs estimated (within the IVIVC/constrained fit)

Within that constrained fit, the release shape γ can be estimated as one shared value or fixed at 1.0 (the PBPK dissolution β). Both are reported:

Endpoint n PBPK PopPK, γ estimated (≈0.8) PopPK, γ = 1.0
Cmax 48 2.00–4.15 1.70–4.60 1.00–6.40
Joint (Cmax & AUC₀–t) 48 1.95–4.10 1.65–4.55 1.00–6.35

γ estimated matches the PBPK safe space; γ = 1.0 inflates it badly — because β = 1.0 is the in-vitro dissolution shape, whereas the PopPK γ is the in-vivo input shape (dissolution folded with gut absorption and transit) and is not 1. So γ is estimated, not fixed. (Full table: GAMMA_COMPARISON_SUMMARY.md.)
